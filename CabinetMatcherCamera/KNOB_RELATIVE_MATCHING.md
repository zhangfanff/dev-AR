# 1.6 随旋钮尺寸变化的文字匹配范围

项目 `G:\AndroidStudioProjects\CabinetMatcherCamera`，应用仍为“开关柜摄像头”，包名 `com.example.cabinetmatcher.camera`，版本号 8 / `1.6-knob-relative-matching`。可覆盖安装摄像头实验版，不修改光流版和光流简版。

## 当前匹配条件

对于正在处理的旋钮，框的宽度为 w、高度为 h，旋钮中心到文字框中心的距离为 d：

```text
d ≤ sqrt(w² + h²)

文字在该旋钮框外的面积 / 文字区域总面积 ≥ 1/3
```

距离恰好等于旋钮框对角线、框外面积恰好三分之一都允许。判断各自使用很小的浮点误差容差。

- 距离阈值为每个旋钮分别计算，不受整幅图像宽高影响。旋钮在画面中等比例放大，匹配距离也按同一比例增加。
- OCR 文本区域通常是四边形，使用这个实际多边形与当前 YOLO 旋钮矩形框的相交面积；不使用文字外接矩形代替倾斜文字多边形。没有多边形时使用文本矩形框。
- 零面积文本区域不允许匹配；仅接触边界不会产生正的重叠面积。
- 面积条件**替代**旧的“文本中心必须位于旋钮框外”。即使中心仍在旋钮框内，只要至少三分之一文本面积位于框外，也可以匹配。
- 条件针对当前旋钮判断，不要求文字避开所有其他旋钮。

方向/扇区仍需满足页面设置。旋钮置信度优先、最近可用文字、一对一占用规则不变；先几何配对再做匹配区域 OCR，识别失败不重新分配其他区域。

## 页面与排查

删除原“最大匹配距离（图像对角线 %）”和“额外侧向限制（图宽 %）”输入，以固定规则说明代替。旧保存状态中的这两个数值不会恢复到新逻辑中。

1. 正常选择模型、开启摄像头、开始识别。
2. 发现异常时暂停，查看匹配区域原图预览中的 `距离 实际值 / 当前旋钮上限 px`、`框外面积百分比`、夹角及 OCR 状态。
3. 无几何配对时，可查看当前旋钮的距离上限及最近候选的拒绝原因；如“文本框位于当前旋钮框外的面积不足三分之一”或“文字与旋钮距离超出阈值”。
4. JSON 的 `parameters.distance_basis` 为 `per_knob_box_diagonal`，倍率为 1，最小框外比例为 `1/3`。全图统一最大距离和图像对角线比例字段为 null。
5. 每个旋钮结果、实际配对及候选分别记录有效的距离上限；配对和候选记录 `text_outside_knob_area_ratio`。`max_distance_processing_px` 或候选/旋钮记录中的 `max_distance_processing_px` 表示处理图坐标，`max_distance_px` 表示导出的源图坐标。

原有低置信度、空文本、异常区域的保留、原图放大预览、灰色未选中框、暂停固定结果、JSON/PNG 导出继续保留。可参考 [MATCH_REGION_DEBUG.md](MATCH_REGION_DEBUG.md)；其中未修改匹配规则的描述属于历史 1.5 版本。

## 实现入口

- `core/GreedyMatcher.matchByKnobSize` 为当前摄像头推理入口。
- `core/TextOverlap` 计算文字多边形在旋钮矩形框外的面积比例。
- `core/MatchReport.maxDistanceFor` 返回当前旋钮的距离阈值。
- 历史绝对距离的 `GreedyMatcher.match` 重载仅供已有调用和回归测试兼容；摄像头 `CabinetPipeline` 始终使用新入口。
