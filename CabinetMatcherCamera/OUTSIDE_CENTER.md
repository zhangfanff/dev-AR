# 文本中心必须位于当前旋钮框外

版本：`1.3.1-outside-knob-center`，versionCode 5。

新增匹配硬条件，应用于下、上、左、右、四向同时所有模式：

```text
允许候选 = 文本中心位于当前旋钮包围框外
         且满足方向扇区、距离、额外侧向限制
         且未被更高优先级旋钮占用
```

若旋钮框为 `[x1,y1,x2,y2]`，文本中心为 `(cx,cy)`，仅当 `cx < x1 或 cx > x2 或 cy < y1 或 cy > y2` 时允许继续匹配。框内、四条边和四个角均排除；不额外增加像素边距。中心使用现有 Detection 的文本四边形顶点均值（无四边形时为矩形中心）。

这是**中心点约束**：文本框可以部分重叠旋钮框，只要中心在外面；并不要求两个框完全不相交。判断针对当前旋钮，不因为文本位于其他旋钮框内而全局删除它。被拒绝候选不会占用文本名额，也不会进入当前旋钮的文字方向分类/OCR 识别队列。

旋钮置信度优先、一对一、扇区、距离规则保持。若 YOLO 框过大，把真实标签中心也包进来，这个真实标签同样会被排除；本版本不再保留旧版“框过大时允许内部标签”的例外。

JSON 参数新增 `text_center_must_be_outside_knob_box=true`、`knob_box_boundary_counts_as_inside=true` 和条件表达式。候选拒绝原因新增 `text_center_inside_knob_box`；全部文本中心均在当前框内时，旋钮原因是 `no_text_outside_knob_box`，界面也会显示对应中文说明。
