# 1.6 旋钮相对距离与文本框外面积验证

日期：2026-10-23。摄像头实验版 `com.example.cabinetmatcher.camera`，versionCode 8 / `1.6-knob-relative-matching`。

- Debug APK、Android 测试 APK、Lint 构建通过，无 Lint 错误。
- 65 项 JVM 测试通过，包括 53 项已有测试和 12 项新规则测试：对角线距离边界、等比例缩放、画布尺寸无关、不同旋钮独立阈值、恰好三分之一、略低于三分之一、倾斜多边形与外接矩形差异、完全包含、零面积、仅接触边界、一对一/优先级/失败不重配及方向约束。
- 11 项 Android 模拟器测试通过：3 项新规则 JSON 导出，4 项预览坐标与绘制/导出回归，2 项匹配区域与资源回收回归，1 项示例图真实 YOLO + 两种 OCR + 文字方向及手部模型运行，1 项相机连续处理/暂停/模型切换回归。
- 相机真实流程输出的 JSON 确认使用每旋钮对角线，倍率为 1，最小框外比例为 1/3，旧图像比例字段为 null，文本中心框外限制为 false。
- APK 身份、ARM64 架构、无网络权限和全部模型资产 SHA-256 校验通过。光流版与光流简版源代码和资产未修改。

`match-debug-*` 为原诊断视图的合成 OCR 失败场景，保留历史绝对距离接口构造测试数据，用于验证失败时不隐藏区域，不代表新版摄像头距离阈值。`camera-live-result.json` 是当前摄像头新规则的实际流程输出；相机画面为模拟器生成内容。

测试仅在本地 x86_64 Android 模拟器执行，没有连接或安装到实体手机，也未针对用户具体漏匹配柜图验证效果。实体手机距离变化时仍需实测。日志和示例数据见 `validation/knob-scale/`。
