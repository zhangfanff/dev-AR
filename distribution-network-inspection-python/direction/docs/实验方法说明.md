# 实验定义与解释范围

## 参考标注与坐标

图像原点为左上，横轴向右、纵轴向下；角度以图像向上为零，向左为正。参考线每段从首点到末点的向量为(dx,dy)，有向角由atan2(-dx,-dy)计算。线轴角按180度周期处理，有向箭头按360度周期处理。

同一方向组的折线段按长度进行倍角平均，得到该区域的参考线轴。只有该组所有参考线均确认箭头可靠时，才计算该组的有向参考角。参考来自人工线，不使用被测算法的输出选择真值。

主匹配采用线轴最小角距与匈牙利一对一分配。误差阈值预设5度，用于方向精确率和召回率；同时报告不依赖该阈值的角度误差。近水平时另报有向角误差及超过90度的反向错误，避免线轴等价性掩盖出线方向错误。

## 原部署方法

固定票箱方案的参数为：区域0–60%和40–100%，最小面积50像素、主长宽比2.0、残差长宽比1.2、端点扩展1.2、15度票箱、近水平75度边界、备选至少2票且与主方向至少相差10度。候选先按数量投票，箱内才按检测置信度乘线性度加权。

端点来自主方向投影极值处的实际像素，不替换成理想轴上的投影点。保留原Float中间计算和扫描/排序语义。JVM一致性检查使用外部DPCA参考文件，Point和日志由桩实现提供。

端点等比例扩展不改变固定端点的夹角，但改变主长宽比过滤。改变扩展参数后必须同时查看候选数量、拒绝原因与方向召回率，不能只比较成功输出的角度误差。

## 概率方向扩展

几何候选提取保持相同。对候选倾角建立轴向von Mises混合密度：

`p(theta) = sum_k pi_k * exp(kappa_k*cos(2*(theta-mu_k))) / (pi*I0(kappa_k))`

角度在数学表达中使用弧度，theta的定义域长度为pi。双角处理线轴的180度周期。质量权重仍由confidence*linearity给出；加权似然采用权重总和等于实例数的归一化。1/2分量模型使用加权BIC型准则选择，样本数采用独立候选实例数量，而不是掩码像素数量。多分量要求每分量至少2个硬分配候选且均值至少相差10度，最大分量数为2。集中参数上限500，用于避免退化拟合。

概率聚合与固定票箱使用相同的几何候选，分组结果通过人工方向标注评价。

## 不确定性区间

在已发现的分量内，重采样导线实例；每个实例按PCA轴划分最多8个空间块，块内最多均匀保留256点，再对块有放回抽样。每次重新计算端点、质量过滤和方向均值。默认200次，随机种子由图片键固定。

围绕点估计展开线轴角后，使用重采样角度的2.5%与97.5%分位数形成近似95%百分位区间；有效重采样不足时返回“区间不可用”，不伪造窄区间。同时拟合重采样角度的圆周集中程度，供诊断使用。

区间条件于已识别的候选分组、现有掩码及所设重采样模型，未重新训练分割网络，也未在每次重采样中重新选择分量数。因此不代表完整的分割模型认知不确定性或无条件95%覆盖保证。Bootstrap并不会自动消除系统性偏差；需报告对人工参考的实际覆盖、区间宽度和区间可用率。

结果同时报告所有参考方向上的覆盖（缺失方向/区间记未覆盖）和可用匹配区间上的条件覆盖，防止只统计容易成功的方向。多个支路分别输出分量与区间，不把无关方向平均成单一角度。

## 数据使用

角度实验仅含50张自采集配网照片，不使用TTPLA。通过原始DJI XMP筛选近垂直俯视视角：俯仰距−90度不超过5度且横滚绝对值不超过5度，两项元数据均需存在。人工仍可把图像标为斜视或不确定；此类图像作为视角剔除单独计数，不作为无导线负样本，也不加入误差、召回或区间覆盖统计。

开发22图，包括原分割训练图18张和验证图4张；它们用于调参，不能作为未见图像的性能证据。测试28图包括原测试图2张和额外现场图26张。额外现场图的文件名不属于原分割数据的任何分区，并额外检查了原文件与派生像素的重复。重复文件和具有相同现场杆塔标识的同日CENTER复拍只保留第一张。图片选择不使用模型预测质量。

主要实验用相同冻结模型的预测掩码，方向真值由人工参考线提供。24张原数据有分割GT，可额外作掩码几何诊断；26张新现场照片没有分割GT，不伪造GT或把缺失掩码当空图。指定both时GT模式只使用有GT的图像，报告其有效数量；与预测模式总体样本不同，不直接解释两组总体差为纯分割误差。

先完成开发标注，确定参数，冻结代码与清单哈希，然后运行测试。现有图像级划分不能证明线路或航次独立，部分相邻图片也不是独立观测。局部参考仅评价图像平面方向，不等于飞机真实航向误差或闭环飞行精度。

## 软件验证与科学证据

更新后用54组相同输入核对原Kotlin与Python（26组合成边界输入及28组本地测试图预测掩码）；另通过14项软件检查和临时合成数据的开发、冻结、测试流程检查，包括视角剔除与缺失GT不误作负样本。这些只验证实现，不替代人工参考实验。具体数值见validation目录的报告。

科学证据必须来自人工确认标注后产生的真实结果。若区间覆盖不足或概率方法不优于原方法，应如实报告并在开发集分析原因，不预先决定优胜者。
